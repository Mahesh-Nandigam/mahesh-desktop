# ⚡ mahesh-desktop 

### *"Siri for your Laptop. But 100x smarter & stealthy."* 💻🔥

Meet **mahesh-desktop** — the sovereign AI assistant and screen pilot built specifically for Windows laptops and PCs. 

Designed for **classroom stealth & ultimate productivity**: trigger with a quick global hotkey (`Alt + M`), silently analyze professor slides on screen (`Alt + S`), auto-type emails and assignments, and launch workflows hands-free.

---

## 🌟 Superpowers

* ⌨️ **Stealth Floating HUD (`Alt + M`)** — Pops up a sleek, glassmorphic spotlight bar over any app (VS Code, Chrome, PDFs, Zoom).
* 👀 **Classroom Slide & Screen Vision (`Alt + S`)** — Takes a silent screenshot of what’s on your screen and explains the slide, code, or math problem instantly.
* ✍️ **Ghost Typer** — *"Draft an email to Prof asking for assignment extension"* $\rightarrow$ Mahesh generates it and automatically types it into Gmail/Notion at your cursor.
* 📂 **Workflow Launcher** — *"Open my full stack project in VS Code and launch YouTube lofi"* $\rightarrow$ Executes your entire workspace in 1 second.
* ⚙️ **Windows System Control** — Mute sound, check battery life, launch apps, and manage processes.

---

## 🚀 Quick Launch
```bash
# Clone the vibe
git clone https://github.com/Mahesh-Nandigam/mahesh-desktop.git
cd mahesh-desktop

# Run Mahesh Desktop
python main.py
```

*Press `Alt + M` anytime to toggle the floating HUD bar.* 🚀
